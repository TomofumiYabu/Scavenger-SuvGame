## 実装済み

仮称「AFTERLIGHT — 残光の街」。7行×7列の固定六角形マップと六方向の移動・発見範囲、地形ごとの有限な物資収集、資源消費、負傷、休息、物資使用、48時間の制限、通信塔での脱出、死亡・時間切れ、探索ログ、ブラウザ内自動保存と復元。日本語 UI、操作説明、再開始の確認、デスクトップ・狭幅のレイアウトを実装。

移動・探索・休息・物資使用・送信に、時間・資源消費・回復量・不可能な理由を表示する。回復上限による切り捨て、避難所の体力回復、送信の満腹度・水分消費も説明。実行前に分かる資源枯渇・負傷・死亡・時間切れの危険を案内する。

保存は schema v2 / content v7。旧schema v1とv2/content1〜6から、所持品・探索履歴・イベント状態・乱数・勝敗を保持して移行する。旧v1とcontent1・2には追加4種を0個で補い、content3以前の地面だけを空として開始する。content4/5/6の地点に残した物は全数量を保持する。旧v1とcontent1〜5には負傷なしを補い、体力の減少から負傷を推測しない。content6の軽傷も保持する。content5/6の探索方法・待機・全6件の解決履歴も保持する。旧保存の過去の行動や死因は推測せず、振り返りは移行後の行動から記録する。過去の収穫やイベントを読み込み時に再生成しない。読み込みでは書き込まず、旧内容の原文を初回上書き前に検証済みアーカイブへ残す。旧v1の保存キーは変更せず、旧バックアップから復元できる。未知形式は保護し、ストレージ障害時は書き込みを止めてメモリ内継続を通知する。保存先はブラウザのlocalStorage。

選択イベントは6件。従来の「崩れた備蓄庫」「残された処置台」「消えかけの火」は対応地形への移動後に発生する。追加した「封じられた配送車」（道路）、「雨水回収槽」（緑地）、「予備電源の唸り」（通信塔）は通常探索の費用・収穫を確定した後、生存・救助期限内なら発生する。各イベントは1プレイ1回。部品・包帯・飲料水を使う選択と、所持品を使わない選択を比較でき、慎重な探索では一部の追加作業が0時間になる。選択待ちには確定した探索方法も保存し、再読込後も同じ条件で再開する。選択が終わるまで通常行動と拾う・置く操作は止まるが、無料で立ち去ることはできる。

AL-005ではUIを分割し、イベント選択の結果をイベント欄に一時表示する。選択した行動、実際のステータス・アイテム・時間の変化、危険と終了状態を示し、見出しへフォーカスを移す。「マップへ戻る」と現在地タイルを選択し、フォーカスとスクロールを合わせる。マップのプレビュー、ダイアログ、画面内だけの移動では結果を保ち、次の実行可能なゲーム行動・リセット・成功した復元で消える。結果はセーブに含めず、新しい保存項目も追加していない。通常の更新は必要な部分だけを書き換え、操作位置を保つ。無効な操作には近くに理由を示し、削除された操作位置からは読める操作領域へフォーカスを移す。ダイアログのキャンセル・Escapeは呼び出し元へ戻り、リセット・復元の成功時は現在地・イベント・終了状態へフォーカスする。

AL-010では廃墟の手早い探索・備蓄庫の深掘りによる体力−10に、持続する「軽い負傷」を連動させた。負傷中の移動・探索は1時間ごとに気力を追加で2消費し、移動8・手早い探索12・慎重な探索20となる。負傷は重ならず、新たに負った行動には追加消費を遡って課さない。包帯・救急キット、診療所の処置、避難所の休息・睡眠で解消できる。体力100でも治療可能。出来事の選択などには追加消費を課さず、避難所以外の休息や食事・飲料では治らない。状態と追加消費を案内し、詳しい説明は開いて読める。イベント結果にも負傷状態の変化を表示する。
