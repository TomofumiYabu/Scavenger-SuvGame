## Cloud の保存状態

`install_script`（依存導入とビルド）および `start_skill`（既存チェックアウト利用、開発サーバー起動、検証、公開との区別）を設定ドラフトへ保存済み。ネットワーク許可・秘密情報の追加は不要だった。

ドラフト保存は公開操作ではない。環境設定で確認・保存したうえで環境を公開する必要がある。別 Cloud タスクへの復元、GitHub への push、静的サイトの公開は未実施。
