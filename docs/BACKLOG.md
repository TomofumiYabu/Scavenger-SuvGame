AL-001は実装・自動検証完了（2026-10-16）。5種の行動で費用・回復・実行可否と理由を共通のルールから表示し、資源枯渇・廃墟負傷・最終時間の危険を案内する。既存の費用・回復順序・勝敗・乱数・v1保存は維持。AL-001完了時点では75件の単体テストと17件のChromium E2Eが成功し、320/390px幅とキーボード操作も確認した。第三者による理解しやすさの試遊評価は未実施。

AL-002/003は実装・自動検証完了（2026-10-16）。AL-004に伴い現行の保存は schema v2 / content v2。content v1からの読取専用移行に対応する。v1の元データを保持し、移行直後の最初の自動保存から、ひとつ前の状態へ戻せる。未知形式は保護し、確認済みリセット/復元時は元データをアーカイブする。ストレージ障害時は危険な書き込みを止め、メモリ内継続を通知する。

イベントは3件。「崩れた備蓄庫」（`collapsed-cache`）は生存中に初めて廃墟へ入ると発生し、安全な回収・危険な深掘り・無料で立ち去る選択がある。「残された処置台」（`clinic-supplies`）は診療所で水を使う処置・包帯を持ち帰る選択・無料で立ち去る選択、「消えかけの火」（`shelter-embers`）は避難所で食料と水を使う温かい食事・空腹と渇きを代償に体力と気力を回復・無料で立ち去る選択を持つ。避難所イベントは開始地点B6から避難所へ初めて戻った時に発生する。いずれも1プレイ1回で、初期配置・読込・探索では発生せず、未解決中は再読込後もイベントに留まり通常行動を止める。P1全体のイベント数は後続段階で6〜12件を目標とする。

AL-002/003の統合後に `npm run check` が成功: 単体テスト109件、Chromium E2E 23件、型検査と本番ビルド。デスクトップと320px幅の画面も目視確認済み。人による試遊評価は未実施。保存はブラウザのlocalStorageのみで、任意のインポート/エクスポートや完全なタブ間同期は対象外。
