# AFTERLIGHT — 残光の街（仮称）仕様 v0.1

## 体験

荒廃した近未来の都市。最後の救難電波が途絶えるまで、あと48時間。避難所を出発し、都市の残骸から食料・水・部品を集め、北東の通信塔で救難信号を送る。一人用、日本語、ターン制。既存作品からは探索と資源配分の緊張感を参考にし、固有の設定や素材は流用しない。

## 最小機能

- 7×7 の固定マップ。東西南北の隣接地点へ移動。現在地と隣接地点を発見し、未発見地点は霧で隠す。通信塔の目印は開始時から表示する。
- 地形は廃墟、道路、緑地、診療所、避難所、通信塔。地点を選んで移動先を確認できる。
- 地点ごとの探索は1回。地形に応じた物資が得られ、廃墟では一定確率で負傷する。
- 体力、満腹度、水分、気力を0〜100で管理。移動・探索・休息・アイテム使用・救難信号送信は1時間消費する。
- 移動: 気力−6、満腹度−3、水分−4。探索: 気力−10、満腹度−5、水分−6。
- 休息: 気力＋35、満腹度−6、水分−8。避難所では体力＋8も得る。
- 食料: 満腹度＋35、水: 水分＋40、包帯: 体力＋30。使用時は満腹度−1、水分−2の基礎消費がある。回復は上限100。
- 満腹度または水分が0の各ターンで、それぞれ体力−12。体力0で死亡。48時間経過で救助機会を失う。
- 開始時: 体力100、満腹度80、水分80、気力85、水2、食料2、包帯1。スクラップは0。
- 通信塔でスクラップ3個を使い救難信号を送ると脱出成功。48時間目の送信も成功とするが、その行動で体力が尽きた場合は失敗。
- ログは直近12件。すべての確定行動後に自動保存。再読込で続きから遊べる。新しい探索の開始時は確認ダイアログを出す。
- 保存できない環境では画面に通知し、メモリ上で継続する。破損・旧形式のセーブは通知して新規開始する。

## 完了条件

ブラウザで移動・探索・休息・物資使用ができ、資源変化とログを確認できる。実際の行動列で脱出でき、死亡・時間切れ後は進行しない。再読込で保存状態を復元する。型チェック、ルールテスト、本番ビルド、Chromium の操作テストが成功する。静的成果物がサブパス配信でも読み込める。
