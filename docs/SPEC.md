# AFTERLIGHT — 残光の街（仮称）仕様 v0.1

## 体験

荒廃した近未来の都市。最後の救難電波が途絶えるまで、あと48時間。避難所を出発し、都市の残骸から食料・水・部品を集め、北東の通信塔で救難信号を送る。一人用、日本語、ターン制。既存作品からは探索と資源配分の緊張感を参考にし、固有の設定や素材は流用しない。

## 最小機能

- 7行×7列・49地点の固定六角形マップ。上頂点型（pointy-top）の odd-r 配置で、0始まりの奇数行を右へ半セルずらす。辺を共有する最大6方向の隣接地点へ移動。現在地と隣接地点を発見し、未発見地点は霧で隠す。通信塔の目印は開始時から表示する。
- 地形は廃墟、道路、緑地、診療所、避難所、通信塔。地点を選んで移動先を確認できる。
- 地点ごとの探索は1回。地形に応じた物資が得られ、廃墟では一定確率で負傷する。
- 体力、満腹度、水分、気力を0〜100で管理。移動・探索・休息・アイテム使用・救難信号送信は1時間消費する。
- 移動: 気力−6、満腹度−3、水分−4。探索: 気力−10、満腹度−5、水分−6。
- 休息: 気力＋35、満腹度−6、水分−8。避難所では体力＋8も得る。
- 食料: 満腹度＋35、水: 水分＋40、包帯: 体力＋30。使用時は満腹度−1、水分−2の基礎消費がある。回復は上限100。
- 満腹度または水分が0の各ターンで、それぞれ体力−12。体力0で死亡。48時間経過で救助機会を失う。
- 開始時: 体力100、満腹度80、水分80、気力85、水2、食料2、包帯1。スクラップは0。
- 通信塔でスクラップ3個を使い救難信号を送ると脱出成功。48時間目の送信も成功とするが、その行動で体力が尽きた場合は失敗。
- ログは直近12件。すべての確定行動後に自動保存。再読込で続きから遊べる。新しい探索の開始時は確認ダイアログを出す。
- 保存できない環境では画面に通知し、メモリ上で継続する。破損・非対応形式のセーブは通知して新規開始する。四角形マップ時代のv1セーブは同じ地点ID・保存キーのまま使用でき、読み込み時に現在地の六角形隣接地点を追加発見する。探索済み地点、資源、時間、乱数、ログ、勝敗は保持する。過去の経路は保存していないため、過去の全訪問地点に新しい発見範囲を遡及適用しない。

六角形化により開始地点B6から通信塔G1までの最短移動は7回（従来の四方向は10回）。移動1回の消費と48時間制限は維持する。最短経路の移動だけなら、7時間・気力42・満腹度21・水分28を消費する。探索や補給を含むバランスの再評価は今後の課題。

## 行動前の案内

移動・探索・休息・物資使用・送信の各ボタンに、所要時間と消費する能力値・所持品を表示する。回復を伴う行動は回復量と現在の値から実際に回復する量を示す。回復は上限100で止まり、その後に満腹度・水分を消費する（例: 水分90で飲料水を使うと、100まで回復して2消費し98になる）。避難所の休息では体力＋8も表示する。

実行できない場合は、終了状態、隣接していない、気力不足、探索済み、所持数不足などの理由をボタンのそばに表示し、読み上げの説明にも関連付ける。行動可能な場合は、現在の状態に応じて満腹度・水分が0になる体力消耗、廃墟での負傷の可能性、体力が尽きる危険、最後の1時間での救助機会の喪失を案内する。最終時間の送信は体力が残る場合に脱出でき、体力が尽きる場合は死亡が優先する。負傷の実際の抽選結果は事前表示しない。プレビューでは時間・状態・乱数を変更しない。

## 完了条件

ブラウザで移動・探索・休息・物資使用ができ、資源変化とログを確認できる。実際の行動列で脱出でき、死亡・時間切れ後は進行しない。再読込で保存状態を復元する。型チェック、ルールテスト、本番ビルド、Chromium の操作テストが成功する。静的成果物がサブパス配信でも読み込める。
